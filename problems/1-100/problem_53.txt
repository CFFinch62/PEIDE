Problem 53: Combinatoric Selections

<p>There are exactly ten ways of selecting three from five, 12345:</p>
<p class="center">123, 124, 125, 134, 135, 145, 234, 235, 245, and 345</p>
<p>In combinatorics, we use the notation, $\displaystyle \binom 5 3 = 10$.</p>
<p>In general, $\displaystyle \binom n r = \dfrac{n!}{r!(n-r)!}$, where $r \le n$, $n! = n \times (n-1) \times ... \times 3 \times 2 \times 1$, and $0! = 1$.
</p>
<p>It is not until $n = 23$, that a value exceeds one-million: $\displaystyle \binom {23} {10} = 1144066$.</p>
<p>How many, not necessarily distinct, values of $\displaystyle \binom n r$ for $1 \le n \le 100$, are greater than one-million?</p>

Hint:
1. We need to count how many combinations C(n,r) exceed one million for n from 1 to 100
2. Strategy:
   - Calculate C(n,r) for all n from 1 to 100 and r from 0 to n
   - Count how many values exceed one million
3. Implementation:
   - Use dynamic programming to compute combinations
   - Use logarithms to avoid overflow with large numbers
   - Compare with log(1000000) instead of 1000000
4. Optimization:
   - Use symmetry: C(n,r) = C(n,n-r)
   - Stop when C(n,r) exceeds one million
   - Use memoization to store computed values
5. Key points:
   - Need to handle large numbers
   - Consider all valid combinations
   - Count only values exceeding one million
